# 🎓 AI-Powered Learning Management System

🌐 **Live Project:** [View Application](https://ai-learning-management-system-daog.vercel.app/)




## 📖 About the Project

This is an **AI-Powered Learning Management System** built using **Python and Django**.

The main idea behind this project is to bring different academic activities into one platform. Students can access courses, lessons, assignments, quizzes, notes, announcements, and track their learning progress.

The system also includes an **AI-powered learning assistant** that helps students ask questions and understand concepts while studying.
